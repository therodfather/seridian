# Flow: Create & publish a form

1. **Basics** — name, public slug, description  
2. **Fields** — add text/email/phone/textarea/number/select/checkbox/url/date  
3. **Settings** — submit label, success message, redirect, notify webhook  
4. **Publish** — go live, copy `/f/{slug}` and Formspree-style API URL  

Optional: Workflows → trigger **Form submission** (filter by slug) → HTTP / create issue / etc.
